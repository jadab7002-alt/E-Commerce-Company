# E-Commerce Company: SQL Business Analysis

## Overview
This project analyzes an e-commerce company's database using MySQL to answer
10 business questions across four areas: Customer Insights, Product Analysis,
Sales Optimization, and Inventory Management.

## Business Context
- **Customer Insights:** Understand the customer base to tailor marketing strategies.
- **Product Analysis:** Evaluate product performance to inform stock and sales strategies.
- **Sales Optimization:** Analyze sales data to identify trends, opportunities, and areas for improvement.
- **Inventory Management:** Manage stock levels to ensure availability while minimizing excess inventory.

## Database Tables
`customers` | `orders` | `orderdetails` | `products`

## SQL Concepts Used
Joins, GROUP BY / HAVING, subqueries, CTEs, window functions (`LAG`),
date functions (`DATE_FORMAT`, `STR_TO_DATE`), and aggregations.
